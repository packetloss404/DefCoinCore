# Historical release notes (upstream archival)

> **Status: upstream archival reference.** The files in this directory
> are upstream **Litecoin Core** release notes (0.10.2.2 through 0.21.2),
> retained for historical context while the codebase is being rebranded
> for Defcoin Core. They are **not** Defcoin Core release notes.

For current Defcoin Core release notes see:

- `../release-notes.md` — the in-progress release-notes template for the
  next Defcoin Core release.
- `../release-notes/` — the corresponding **Bitcoin Core** historical
  archive (also upstream archival reference).

Defcoin Core release notes will be archived under `../release-notes/`
once the first Defcoin Core release is cut.
